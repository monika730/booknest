# BookNest

BookNest is a book-discovery and reading-list application built with React, Vite, React Router, and an Express API.

## Run the project

```sh
npm install
npm run dev
```

The dev command starts the React app at `http://127.0.0.1:5173` and the Express API at `http://127.0.0.1:3001`. Vite proxies `/api` requests to Express.

## Useful commands

```sh
npm run lint
npm run build
npm run server
```
